# Evidence Atlas Internal Ledger

Last updated: 2026-07-11

This file is an internal provenance ledger. It is not copied into `dist/`.

## Evidence Classes

- `Artifact`: code, tests, manifests, architecture records, or delivered files.
- `Contract`: governance rules and explicit operating contracts.
- `Profile`: stable user-confirmed profile statements; not independent artifact proof.
- `Delivered`: behavior verified in the public website project itself.

## Public-Safety Rule

The public dataset may describe methods, decisions, boundaries, artifacts, and verification structure. It must not expose account values, positions, returns, private family facts, psychological sessions, employer-sensitive facts, tokens, IDs, local paths, or live operational state.
