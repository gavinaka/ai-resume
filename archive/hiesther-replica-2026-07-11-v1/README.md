# AkaGavin Personal Website

纯静态个人网站。视觉与交互结构参考 `https://hiesther.me/`，全部内容、人物素材与项目档案均替换为 AkaGavin 的公开层信息。

## 打开方式

直接打开 `index.html` 可以浏览主要功能。为保证 iframe、浏览器存储和跨页面跳转行为一致，建议在本目录启动静态服务器：

```powershell
py -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 页面结构

- `index.html`: 终端启动、桌面世界、作品集和页面路由。
- `infinite-canvas.html`: 可编辑无限画布。
- `site-data.js`: 全站公开内容与项目档案。
- `script.js`: 启动动画、窗口系统、桌面交互和循环退出。
- `canvas.js`: 画布拖拽、缩放、编辑、连线、撤销、保存与图片上传。
- `pages/project.html`: 项目详情通用模板。
- `assets/`: 自托管字体与 AkaGavin 专属生成插画。

## 画布操作

- 滚轮或双指：缩放画布。
- 拖动空白处：平移画布。
- 拖动卡片顶部：移动卡片。
- 拖动卡片右下角：缩放卡片。
- 双击文字：编辑内容。
- 连线模式：从一张卡拖到另一张卡。
- `Ctrl+Z`：撤销上一步卡片操作。
- 保存：写入当前浏览器的 `localStorage`。
