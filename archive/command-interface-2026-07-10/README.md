# AkaGavin Command Interface Site

这是一个纯静态个人网站，定位不是传统简历，而是 AkaGavin 的个人决策系统与 Command Interface 展示页。

## 文件

- `00_PROFILE_BRIEF.md`：画像锚点、公开边界和内容原则。
- `index.html`：Command Interface 页面结构。
- `styles.css`：高级深色响应式视觉系统。
- `script.js`：首屏动态决策网络、HUD 动效和导航高亮。

## 本地打开

直接双击 `index.html` 即可在浏览器打开。
