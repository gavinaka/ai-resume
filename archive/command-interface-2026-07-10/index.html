Decision Doctrine

决策原则必须像协议一样稳定。

这些规则约束的是判断质量，而不是制造漂亮叙事。它们决定系统长期是否可复盘、可审计、可升级。

RULE 01

事实、推断、假设、未知分层。

任何复杂判断先拆层，防止把主观看法误当成事实。

RULE 02

看不懂就不做。

拒绝用仓位或动作掩盖认知空白，空手也是一种决策。

RULE 03

先验证样本，再扩大规模。

规模是验证后的结果，不是验证前的赌注。

RULE 04

流程错误不能被结果洗白。

盈利但违反计划仍然是错误；系统质量和单次结果分开评价。

RULE 05

真源只读，写入审慎。

关键数据由人确认，agent 默认只读消费，避免自动化污染源数据。

RULE 06

能计算的不要交给感觉。

确定性计算层负责口径和结果，AI 判断层负责解释、质疑和行动建议。
